---
title: meta.json fields
description: What you can set in a section's meta.json.
tags: [guide, config]
date: 2026-10-26
---

| Field | Purpose |
| --- | --- |
| `root` | `true` — the directory becomes a menu item |
| `title` | name in the menu |
| `description` | section subtitle |
| `$id` | URL segment |
| `icon` | lucide icon name, e.g. `Cpu` |
| `color` | icon color |
| `order` | menu order (optional) |
